# 三端与子域名

> 一句话：**一份 web 前端（合集 + 游戏），PC/安卓是薄壳，只负责装载。**
> 最后核对：2026-11-15。

## 一、地址与端口

| 用途 | 地址 / 端口 | 归属 | 说明 |
|---|---|---|---|
| 线上入口 | `https://minigames.zhinengtai.xyz` | 本仓 | Cloudflare 隧道回源本机 **8770** |
| 本机现发 | `http://127.0.0.1:8770/` | 本仓 | `npm run serve`（先 `npm run build`） |
| dev | `http://localhost:5370/` | 本仓 | `npm run dev`（Vite，游戏目录原样直发） |
| preview | `http://localhost:5371/` | 本仓 | `npm run preview` |
| 健康检查 | `/health` | 本仓 | 返回 `{ok:true,project:"minigames",port:8770,web:"<构建版本>"}` |

**端口纪律**：8770 只归 minigames。不要占用、重启、杀别的项目端口（8092 同舟、8791 凡梦、8192 qpic、5191 盯盘、8091 回声、8080 平台 BFF、7682 g8）。

## 二、子域名怎么加（全队同一套）

工具在平台仓：`D:\doubao\zhinengtai\tools\cf-domain.mjs`。一条命令同时改 DNS 与隧道 ingress：

```bash
# 先确认目标端口服务真的起着（脚本不看这个，但文档要求）
curl -s http://127.0.0.1:8770/health

# 在平台仓根目录执行（Bash 读不到 User 级变量，用 PowerShell 传进去）
powershell.exe -NoProfile -Command "\$env:CLOUDFLARE_API_TOKEN=[Environment]::GetEnvironmentVariable('CLOUDFLARE_API_TOKEN','User'); node tools/cf-domain.mjs add minigames.zhinengtai.xyz 8770"

# 只读查看当前所有路由
powershell.exe -NoProfile -Command "\$env:CLOUDFLARE_API_TOKEN=[Environment]::GetEnvironmentVariable('CLOUDFLARE_API_TOKEN','User'); node tools/cf-domain.mjs list"
```

当前路由（2026-11-15 实测）：

```

api.zhinengtai.xyz       -> http://localhost:8080
echo.zhinengtai.xyz      -> http://localhost:8091
```

注意：`add`/`rm` 立即改生产 DNS；用完的测试域名必须 `rm` 清掉；不要手改 Cloudflare 控制台 ingress（脚本整体 PUT，会覆盖未同步改动）。

## 三、三端分别怎么跑

### 1) Web（本体）

`npm run build` → `dist/`；`npm run serve` 在 8770 现发。线上就是这条链路。
手机浏览器打开 `https://minigames.zhinengtai.xyz` 可「添加到主屏幕」（PWA：manifest + service worker + `offline.html`）。

### 2) 安卓壳（Capacitor）

- 配置：`capacitor.config.json`，`server.url` 指线上子域名，`errorPath: offline.html`。
- 壳只加载线上页面，**改前端不用重打 APK**。
- 识别端：UA 里带 `MinigamesShell/<版本>`（`appendUserAgent`）。
- 打包：`node tools/bump-shell-version.mjs "说明"`（改壳才需要）→ `npm run build` → `npx cap sync android` → `cd android && gradlew assembleDebug`。
- 产物：`android/app/build/outputs/apk/debug/app-debug.apk`。
- 本机前置：`android/local.properties` 写 `sdk.dir=...`（已在 .gitignore）；JAVA_HOME 用 Android Studio 自带的 jbr。

### 3) PC 壳（Tauri 2）

- 配置：`src-tauri/tauri.conf.json`；`frontendDist` 指向 `../dist` 作为离线兜底。
- 加载顺序（`src-tauri/src/lib.rs`）：
  1. `MINIGAMES_PC_URL` 环境变量 / exe 同目录 `minigames-shell.json` 的 `localBase`（自测覆盖）
  2. `http://127.0.0.1:8770/`（本机现发）
  3. `http://localhost:5370/`（dev）
  4. `https://minigames.zhinengtai.xyz/`（线上）
  5. 都不通：留在包内 `dist`
- 跳转时 URL 带 `?pcShell=<版本>`，门户据此显示「🖥️ PC 版 · 壳 xxx」。
- 打包：`npx tauri build`，产物在 `src-tauri/target/release/`。

## 四、端识别只有一个入口

`public/platform.js` 设置 `window.MINIGAMES = { kind, shellVersion, touch, label, inShell, portalUrl }`。

- `kind`：`web` / `pc` / `android`
- 门户直接读它；任何游戏都可以 `<script src="../../platform.js"></script>` 后读同一个对象。
- **不要在各处自己猜 UA**，口径只在这里改。

## 五、下载入口

门户底部「📥 下载客户端」读同源清单，有两个按钮（没发过的那端自动隐藏）：

| 端 | 同源清单 | OSS 地址 |
|---|---|---|
| PC | `/latest-pc.json` | `sdxcloud/minigames/pc/MINIGAMES_0.1.0_x64-setup.exe`（安装包）+ `MINIGAMES.exe`（免安装） |
| 安卓 | `/latest-android.json` | `sdxcloud/minigames/app/minigames-android-latest.apk` |

`latest-*.json` 由 `publish:pc` / `publish:android` 写入，`dist` 每次构建会被清空，所以同时存一份到 `release/<端>/`，构建时自动还原（`vite.config.js` 的 `mg-games-hub` 插件）。
