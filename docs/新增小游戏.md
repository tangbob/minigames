# 新增小游戏

## 一、最少三步

1. 新建目录 `games/<英文短名>/`（例如 `games/space-shooter/`）。
2. 把游戏整个放进去，入口默认 `index.html`。
3. 在里面写 `game.json`：

```json
{
  "name": "游戏中文名",
  "en": "GAME NAME",
  "emoji": "🚀",
  "desc": "一句话说明玩法，会显示在卡片上。",
  "entry": "index.html",
  "tags": ["单人", "3 分钟"]
}
```

4. 重新 `npm run build`（或 `npm run dev` 时刷新），门户会自动扫描并长出卡片。**不需要改门户代码。**

## 二、硬性要求

- **全部用相对路径**。游戏在 `games/<名字>/` 下运行，引资源写 `css/style.css`、`js/main.js`、`lib/xxx.js`，不要写 `/games/...` 或绝对域名。
- **不要依赖构建工具**。`games/` 是原样拷进 `dist/` 的静态目录，Vite 不会处理里面的代码。要用 npm 包就把打包好的单文件放进 `lib/`（参考 city-racer 的 `lib/three.module.js`）。
- **ES module 用 importmap**（参考 `games/city-racer/index.html`）：

```html
<script type="importmap">
{ "imports": { "three": "./lib/three.module.js" } }
</script>
<script type="module" src="js/main.js"></script>
```

- **不要往 `games/` 里放 `node_modules`、`.git`、构建缓存**。
- 大文件（>10MB）尽量别直接塞进仓库，先和 Bo 商量放 OSS。

## 三、三端适配（可选但推荐）

在游戏页面 `<head>` 里加一行，就能知道自己在哪个端：

```html
<script src="../../platform.js"></script>
<script>
  console.log(window.MINIGAMES); // {kind:"web"|"pc"|"android", shellVersion, touch, inShell, ...}
</script>
```

- `MINIGAMES.touch === true` 时建议显示触控按钮（手机/平板）。
- `MINIGAMES.inShell === true` 时可以提供「🏠 返回合集」入口（`MINIGAMES.portalUrl`）。
- 音频必须等用户手势后再 `AudioContext`，否则手机静音。

## 四、自测清单

- [ ] `npm run build` 通过，`dist/games-index.json` 里有你的游戏
- [ ] `npm run serve` 后 `http://127.0.0.1:8770/` 能看到卡片，点进去能玩
- [ ] 刷新一次，确认没有 404（资源路径都相对）
- [ ] 手机竖屏/横屏至少看一眼布局
- [ ] `npm run verify` 全绿
